# 📚 FIAP Study Manager

Um gerenciador de estudos e tarefas desenvolvido para auxiliar na organização da rotina acadêmica.

Este projeto está sendo desenvolvido durante minha jornada em Engenharia de Software na FIAP, com o objetivo de colocar em prática conceitos de desenvolvimento web e Engenharia de Software.

## 🎯 Objetivo

Criar uma aplicação simples e intuitiva onde o usuário possa organizar suas tarefas, prazos e prioridades em um único lugar.

## 🚀 Funcionalidades

### Versão inicial

- [ ] Criar tarefas
- [ ] Definir data de entrega
- [ ] Definir horário
- [ ] Definir prioridade
- [ ] Visualizar tarefas
- [ ] Editar tarefas
- [ ] Excluir tarefas
- [ ] Marcar tarefas como concluídas
- [ ] Visualizar progresso

### Futuras funcionalidades

- [ ] Criar eventos e compromissos
- [ ] Detectar conflitos entre tarefas e eventos
- [ ] Sugerir prioridades automaticamente
- [ ] Sistema de notificações
- [ ] Armazenamento em banco de dados
- [ ] Sistema de login
- [ ] Responsividade para dispositivos móveis
